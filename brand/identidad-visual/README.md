# Identidad visual de VELARA

Documentación de la identidad visual del proyecto.

## Contenido principal

- logotipo
- versiones positivas/negativas
- papelería
- plantillas
- recursos gráficos
- tipografías y patrones

## Referencia real en el repo

El material visual más completo está en:
- `VELARA_IDENTIDAD_VISUAL/`

## Objetivo

Centralizar todos los recursos visuales para que la marca tenga una base única y sea más fácil mantener consistencia en la web y el material comercial.
