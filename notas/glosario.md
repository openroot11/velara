# Glosario

## Del proyecto

| Término | Qué es |
|---|---|
| **VELARA** | La marca. Taller de cuero y tapicería en Barranquilla. Ver [[proyecto-velara]] |
| **Vault** | La carpeta que abre Obsidian. Aquí es toda la carpeta `valera/`. Ver [[00-mapa]] |
| **MOC** (Map of Content) | Nota índice que enlaza a otras. Aquí: [[00-mapa]] |
| **Embudo de cotización** | El recorrido botón → `/cotizar` → WhatsApp. Ver [[arquitectura-web]] |
| **Design token** | Valor de diseño con nombre (color, tamaño) definido una vez en `tailwind.config.js`. Ver [[identidad-visual]] |
| **SPA** | Single Page Application. El sitio es un solo HTML que cambia de vista con JavaScript |
| **Slug** | El trozo de URL que identifica una página: en `/materiales/lona-nautica`, el slug es `lona-nautica` |
| **`:slug`** | Ruta dinámica: un patrón que atiende muchas páginas (`/materiales/:slug`) |
| **Full-bleed / a sangre** | Elemento que ocupa todo el ancho de la ventana, rompiendo el contenedor centrado |
| **Mega-menú** | Panel grande a todo el ancho que baja del encabezado con columnas de enlaces |
| **Migas de pan** (breadcrumbs) | El rastro «Inicio / Servicios / Tapizado automotriz» en cada página interna |

## Del oficio (tapicería)

| Término | Qué es |
|---|---|
| **Tapizado automotriz** | Renovar asientos, paneles, cielos y consolas de un vehículo |
| **Cielo / techo interior** | El forro de la parte de arriba de la cabina |
| **Forro a la medida** | Cubierta hecha a medida para un mueble, asiento o equipo |
| **Carpa / toldo** | Estructura de lona para un local o negocio |
| **Lona** | Tela recia y recubierta, resistente a la intemperie |
| **Vinilo / cuero sintético** | Material de PVC o poliuretano que imita cuero, usado en tapicería técnica |
