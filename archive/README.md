# Archive

Este directorio sirve para guardar archivos antiguos, experimentales o legacy que ya no son la base activa del repositorio.

## Para qué sirve

- fotos de pruebas
- archivos borradores
- documentos obsoletos
- versiones antiguas de arte o contenido
- material que aún se conserva por historial pero no debería vivir en la raíz

## Regla

Si ya no se usa activamente y solo sirve como respaldo histórico, va aquí.
