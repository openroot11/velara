# Spradling / referencia visual

Este directorio contiene el estudio del sitio de referencia que inspiró la arquitectura del proyecto.

## Qué incluye

- guía de referencia visual
- capturas del sitio base
- análisis de navegación, estructura y patrones de diseño

## Archivo clave

- `referencia-spradling/GUIA-SPRADLING.md`

## Objetivo

Usar la referencia como patrón de estructura y estilo, sin mezclarla con el código activo ni con la identidad final.
