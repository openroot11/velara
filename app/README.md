# App / sitio funcional

La parte operativa del proyecto vive aquí.

## Qué va aquí

- frontend del sitio web
- contenido de páginas dinámicas
- componentes, rutas y data del proyecto
- código que se ejecuta en desarrollo y producción

## Fuente principal

El sitio funcional del proyecto sigue viviendo en:
- `sitio/`

Para dejar la estructura más clara, se ha preparado la ruta canónica:
- `app/sitio/`

La intención es que la aplicación quede agrupada como una sola pieza y el resto del repo quede dedicado a marca, documentación e investigación.
