# Sitio VELARA

Este directorio existe como referencia del sitio comercial de VELARA.

## Descripción

El sitio está construido con React + Vite y su objetivo principal es presentar el taller, comunicar servicios y llevar a la persona a cotizar por WhatsApp.

## Ruta de trabajo

La estructura funcional sigue en:
- `sitio/`

La organización recomendada es:
- `app/sitio/` como ubicación canónica del proyecto web

## Qué debe mantenerse aquí

- componentes
- páginas
- estilos
- datos de contenido
- rutas de navegación
- lógica comercial del formulario de WhatsApp

## Reglas

- No mezclar branding ni documentación técnica dentro de la app.
- Mantener contenido editable separado.
- Respetar los assets reales y no inventar trabajos ficticios.
